# Frontend UI (Angular) – 3D Tic-Tac-Toe Cube

Este contenedor provee la SPA de Angular para el juego Tic-Tac-Toe en un cubo 3D con interacciones modernas y transiciones suaves.

Documentación técnica completa:
- kavia-docs/frontend_ui-arquitectura-y-guia.md

Ejecución (resumen):
- Variables de entorno clave: NG_APP_API_BASE, NG_APP_BACKEND_URL, NG_APP_FRONTEND_URL, NG_APP_WS_URL, NG_APP_NODE_ENV, NG_APP_NEXT_TELEMETRY_DISABLED, NG_APP_ENABLE_SOURCE_MAPS, NG_APP_PORT (3000), NG_APP_TRUST_PROXY, NG_APP_LOG_LEVEL, NG_APP_HEALTHCHECK_PATH, NG_APP_FEATURE_FLAGS, NG_APP_EXPERIMENTS_ENABLED
- Instalar: npm ci
- Desarrollar: npm run start:dev (preview esperado: http://localhost:3000)
- Construir: npm run build
